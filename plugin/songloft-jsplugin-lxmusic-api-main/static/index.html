info 关于插件 v2026.5.25

洛雪音乐API 是 洛雪音源插件 的 API 适配层，为 TV客户端、xiaomusic 等客户端提供统一API。

help 使用说明

快速开始：
1. 在插件市场安装并启用本插件
2. 下载并安装 TV客户端 或 xiaomusic 客户端
3. 在客户端登录界面填写接口地址和账号密码
    示例接口：http://localhost:58091/api/v1/
    账号密码：与网页端一致
