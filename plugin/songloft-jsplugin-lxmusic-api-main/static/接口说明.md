# lxmusic-api 接口说明

> 本插件为 Songloft 的音乐 API 适配壳层，**不附带任何第三方音源数据**。下面所有涉及实际音乐数据的接口都依赖配套的下游源适配插件，使用者需自行负责合规接入。下文示例中出现的「平台标识」`kg/kw/tx/wy/mg` 仅为占位短代，不指向特定第三方平台。

## 基本信息

- **插件名称**: lxmusic-api
- **版本**: v2026.5.25
- **Base URL**: `/api/v1/jsplugin/lxmusic-api`
- **认证方式**: Bearer Token（与主程序一致的登录账号密码）

## 响应格式

### 成功响应
```json
{
  "code": 0,
  "msg": "success",
  "data": { ... }
}
```

### 错误响应
```json
{
  "code": <statusCode>,
  "msg": "<错误信息>",
  "data": null
}
```

## 平台标识

`source` 字段使用下述占位短代之一。实际背后对应的音源由各自的下游源适配插件提供，本插件不绑定任何第三方平台。

| 标识 | 占位名 |
|------|------|
| `kg` | Source A |
| `kw` | Source B |
| `tx` | Source C |
| `wy` | Source D |
| `mg` | Source E |

## 接口列表

### 1. 配置

#### GET `/config`
获取 TV 客户端配置

**请求参数**: 无

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "quality_options": ["flac", "320k", "128k"],
    "default_quality": "320k",
    "sources": ["kw", "kg", "tx", "wy", "mg"],
    "sources_name": {
      "kw": "Source B",
      "kg": "Source A",
      "tx": "Source C",
      "wy": "Source D",
      "mg": "Source E"
    }
  }
}
```

### 2. 搜索

#### GET `/search`
搜索歌曲

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 搜索关键词 |
| `source` | string | 否 | 平台标识，不传则返回空 |
| `page` | number | 否 | 页码，默认 1 |
| `limit` | number | 否 | 每页数量，默认 20 |

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": [
    {
      "id": "歌曲ID",
      "name": "歌曲名",
      "singer": "歌手名",
      "source": "kw",
      "interval": "3:45",
      "img": "封面URL",
      "albumId": "专辑ID",
      "albumName": "专辑名",
      "songmid": "歌曲MID",
      "hash": "哈希值",
      "copyrightId": "版权ID",
      "types": [
        { "type": "flac", "size": "25.6MB" },
        { "type": "320k", "size": "8.2MB" }
      ]
    }
  ]
}
```

### 3. 播放 URL

#### POST `/url`
获取歌曲播放 URL（代理至 lxmusic-jsplugin）

**请求头**: `Content-Type: application/json`

**请求体**:
```json
{
  "songInfo": {
    "source": "kw",
    "songmid": "歌曲MID"
  },
  "quality": "320k"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `songInfo.source` | string | 是 | 平台标识 |
| `songInfo.songmid` | string | 是 | 歌曲 MID |
| `quality` | string | 否 | 音质选项，默认 320k |

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "url": "https://xxx.com/播放地址.mp3",
    "type": "mp3",
    "source": "kw"
  }
}
```

    "tlyric": "[00:00.00]翻译内容...",

---

#### GET `/cache/lyric`
获取缓存歌词

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source` | string | 是 | 平台标识 |
| `songmid` | string | 是 | 歌曲 MID |
| `songId` | string | 否 | 歌曲 ID |

**响应**: 同 `/lyric` 接口
**错误**: 返回 404 如果歌词未缓存

---

#### POST `/cache/lyric`
缓存歌词到主程序

**请求头**: `Content-Type: application/json`

**请求体**:
```json
{
  "source": "kw",
  "songmid": "歌曲MID",
  "songId": "歌曲ID（可选）",
  "lyric": "歌词内容"
}
```

**响应示例**:
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "success": true,
    "message": "歌词缓存成功"
  }
}
```

## 第三方接入指南

### 1. 认证
接入前需要先在主程序登录账号，获取 Token。后续请求在 Header 中携带：
```
Authorization: Bearer <token>
```

### 2. 快速开始
1. 安装并启用本插件
2. 安装并启用配套的源适配插件（提供 URL / 歌词能力，例如 [songloft-plugin-lxmusic](https://github.com/songloft-org/songloft-plugin-lxmusic) 等社区插件）
3. 调用接口时使用 Base URL: `http://localhost:58091/api/v1/jsplugin/lxmusic-api`

### 3. 调用示例

**搜索歌曲**:
```bash
curl -X GET "http://localhost:58091/api/v1/jsplugin/lxmusic-api/search?name=keyword&source=tx" \
  -H "Authorization: Bearer <token>"
```

**获取播放URL**:
```bash
curl -X POST "http://localhost:58091/api/v1/jsplugin/lxmusic-api/url" \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"songInfo":{"source":"tx","songmid":"歌曲MID"},"quality":"320k"}'
```

---

## 注意事项

1. **依赖插件**: URL 和歌词接口依赖配套的源适配插件（`lxmusic-jsplugin` 等），必须先安装并启用
2. **跨域访问**: 浏览器直接访问需要处理跨域，建议通过客户端转发
3. **错误处理**: 接口返回非 0 code 时表示请求失败，请检查 `msg` 字段
