# songloft-plugin-lxmusic

A Songloft JS plugin generated by `create-songloft-plugin`.

洛雪音源 Songloft JS 插件。

## Development

```bash
npm install
npm run dev         # watch + auto-upload to local Songloft
npm run build       # produce dist/lxmusic.jsplugin.zip
npm run validate    # verify plugin.json hashes
```

## Description

第三方音源适配示例插件。本仓库仅提供与宿主 SDK 对接的脚手架代码，**不附带任何第三方音源数据**，使用者需自行负责音源接入合规性。
